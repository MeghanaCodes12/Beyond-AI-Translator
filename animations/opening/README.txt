BEYOND — STANDALONE OPENING ANIMATION

This folder is intentionally independent from the Flet application.

FILES
- index.html       Main animation page
- style.css        Layout + CSS animation timing/easing
- animation.js     Animation sequence controller
- assets/          Approved leaf and separated visual layers

RUN
1. Keep the whole folder together.
2. Open index.html in a browser.
3. The animation starts automatically.

SEQUENCE
empty/light -> water -> droplet -> sprout grows -> leaf grows -> particles -> settle -> title -> loading

IMPORTANT
Do not rename or move the files inside assets unless the paths in index.html are changed too.
